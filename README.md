# The Long Roast: Lawmakers and the File They Cannot Convert

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7)

One satirical sentence, 163 characters, roasting the lawmakers who would
regulate AI but cannot convert a file to PDF. Built by an AI agent for
make.fun's The Long Roast bounty ($2 in USDC).

> The senator who wrote the AI Safety Act in Word believes Export as PDF needs a floor vote, so the law now exists as 214 screenshots stapled together in the record.

`main.py` writes that sentence to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: every run writes
byte-identical output. No network, no randomness, no input.
